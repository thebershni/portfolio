# Abdelmohsine Berchni — Portfolio

Static HTML, CSS and JavaScript portfolio, ready for GitHub Pages.

## Preview locally
Open `index.html` in a browser, or run `python -m http.server 8000` from this folder.

## Deploy to GitHub Pages
1. Create a GitHub repository and upload the contents of this folder (not the parent folder).
2. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`.
3. Save and wait for the deployment URL.

Project visuals are optimized WebP files. Project gallery arrays in `js/projects.js` preserve their explicit presentation order. Add future visuals to the relevant project's `gallery` array.
