# Abdelmohsine Berchni — Portfolio (static HTML/CSS/JS)

No build step. Open `index.html`, or deploy as-is.

## GitHub Pages
1. Create a repo, upload **everything in this folder** (keep `.nojekyll`).
2. Settings → Pages → Deploy from branch → `main` / root.

## Edit content
- Projects, Behance IDs, skills: `js/projects.js` (ID = number in `behance.net/gallery/<ID>/...`).
- Text, experience, contact: `index.html`.
- Colors: CSS variables at the top of `css/styles.css`.

## Behance embeds
Cards open `behance.net/embed/project/<ID>` in an in-site viewer (prev/next, Esc to close), with an "Open on Behance" fallback link.
